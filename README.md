## Develop and build

```sh
npm ci --no-audit --no-fund
npm run dev
npm run build
npm run preview
```

Vite writes the static build to `docs/`. Existing GitHub Pages hosting uses `main` / `docs`; that configuration is preserved. The existing workflow builds and validates the public bundle, uploads an artifact, and publishes only when the source branch is `main`. It rejects stale source revisions before publishing, commits only generated files, and explicitly requests a branch-based Pages build. A source-only push is not deployment success.

The workflow's existing push branch filters support `main` and `portfolio-cyber-ai`. Source changes on `main` run the existing publication flow; other branches can be checked through an intentional workflow dispatch. `docs/build.json` is generated by CI to record the source revision.

## Interaction and accessibility

- `?focus=security`, `?focus=ai`, and `?focus=engineering` select a project view.
- `?project=phish-signal-lab` or `?project=framevigil` opens a case study directly.
- Four semantic buttons change the engineering map's stage and descriptive text; keyboard activation works and the selected state is exposed through `aria-pressed`.
- Native modal dialogs contain keyboard focus and support Escape dismissal. Closing restores focus to the invoking control; a direct-linked case falls back to the selected filter.
- Semantic navigation, a skip link, visible focus indicators, and responsive layouts support keyboard and mobile use.
- Reduced-motion preferences disable the SVG trace animation, reveal motion, and smooth scrolling.
- A no-JavaScript summary provides background and public source links. Fonts have local fallbacks, and the portfolio needs no runtime API or account.
